Download the `import-m3g.py` and install it as an add-on.
I have not yet tested it as a standalone script, and probably won't do that anyways.

**NOTE:** .m3g files have the ability to include animations and textures, however most .m3g files only have meshes, so searching for the .PNG is mandatory. The default UV map that the mesh comes with is perfect and does not need any other UV map if you have the original .PNG file. Thank you.
